## 0.2.9 存储路径说明

- 修复“目录信息”里让人误以为可以手动打开私有目录的说明
- Android 端 CHM 实际存放在：

```text
/data/user/0/com.infinite.chmproto/files/books
```

- 这是 **Android 应用私有目录**，普通文件管理器、电脑 MTP、手机助手都看不到，也不需要手动放文件
- 正确方式是：规则书页 → **导入 CHM** → 从下载 / QQ / 微信等位置选择文件；程序会自动复制到上述目录
- Android 端“目录信息”里已隐藏“复制路径”按钮，并明确提示该目录仅应用自身可访问

## 安装

要求：Android 8.0 或更高。

1. 把 APK 拷到手机
2. 点击安装，允许“安装未知来源应用”
3. 也可以使用 ADB：

```powershell
adb install 无限流角色终端-Android-v0.2.81.apk
```

如果手机里还装着 CHM 原型 `v0.1.x`，它和这个内测包使用同一个包名和调试签名，可以直接覆盖安装；已导入的 CHM 会保留。

## 当前限制

- 还是 debug 签名，不能作为正式长期发布包
- 包名暂时仍是 `com.infinite.chmproto`，正式版会改成正式包名
- 只在 Android 11 模拟器验证，尚未在真实手机和低端机上测试
- 还没有逐项回归所有编辑、导入导出、头像和 ST 操作
- 战斗表格在窄屏下仍可能需要横向滚动
- 规则书搜索依赖 CHM 自带全文索引；没有内置索引的 CHM 需要后续增加页面枚举兜底
- 搜索最多返回 120 条，界面显示前 80 条
- 还没有导入进度、书库删除、最近阅读
- 底部导航和部分页面仍可继续压缩，给正文更多空间

## 工程结构

```text
Android WebView
├─ assets/www/       电脑版 HTML/CSS/JS + mobile.css + mobile.js
├─ android-bridge.js 把 WebView2 消息协议映射到 Android
├─ MainActivity.java Android 文件、CHM 库、搜索、导入导出
└─ org.jchmlib/      纯 Java CHM 解析
```

电脑版原有文件没有被修改；手机版使用独立副本。
